# 01 — Обзор и разделы интерфейса

## Вход

- URL задаётся администратором конкретного развёртывания платформы.
- Страница входа: «Вход в систему» — Email + Пароль.
- Для демонстраций используйте отдельный тестовый аккаунт без доступа к рабочим данным.

## Верхнее меню (навигация)

| Пункт | URL | Назначение |
|---|---|---|
| **Боты** | `/` | Список «Мои боты». Создание, импорт, действия по каждому боту. |
| **Аналитика** | `/analytics` | Статистика по нодам, у которых включён флаг «В статистике». |
| **Диалоги** | `/dialogs` | Журнал сессий пользователей (для разбора/дебага). |
| **Логи пользователей** | `/user-logs` | Подробный лог пути конкретного пользователя (открывается из диалога). |
| **Редактор** | `/editor` | Визуальный конструктор сценария (граф нод) + JSON-редактор. |
| **Тест виджета** | `/widget-test` | Тестовый стенд Web-виджета (chat-widget) для ботов с мессенджером `web`. |
| **Промпты** | `/prompts` | Готовые промпты для LLM-генерации сценариев + спецификация платформы. |
| **Выход** | — | Логаут. |

## Страница «Боты» (`/`)

- Кнопки: **Импорт** (загрузить JSON-файл сценария) и **Создать бота** (открывает редактор с новым сценарием).
- Таблица, колонки: **Название · Описание · Статус · Цикличность · Действия**.
- Действия по каждому боту (видно в записи на аккаунте с ботами):
  - **Мессенджеры** — подключение каналов (Telegram/VK/...): вставить токен, включить.
  - **Предпросмотр** — прогон сценария в встроенном «мессенджере-эмуляторе».
  - **Редактировать** — открыть в редакторе.
  - **Экспорт** — скачать JSON сценария.
  - **Собрать** — собрать/задеплоить бота.
  - **Удалить** — удалить бота.
- **Статус** — вкл/выкл бота. **Цикличность** — см. ниже.

### Цикличность (важный параметр сценария)

Если включена — после попадания в узел `end` диалог при следующем сообщении начинается заново
с `start`. Если бот «перестал отвечать» после конца — обычно нужно включить цикличность.

## Редактор (`/editor`)

Шапка: **JSON редактор · Добавить узел · Сохранить**.

- **Холст** на React Flow: ноды + рёбра (переходы). Зум, fit-view, миникарта.
- **Добавить узел** — добавляет узел типа `message` (тип потом меняется в свойствах).
- Клик по ноде → панель **«Свойства узла»** с вкладками:
  - **Основные** — Название узла, **Тип узла** (выпадающий список из 9 типов),
    переключатель «Начальный узел / Обычный узел», переключатель **Аналитика**
    («В статистике / Не в статистике»).
  - **Содержимое** — поля под выбранный тип (текст, клавиатура, URL, условие и т.д.).
  - **Переходы** — список переходов (regex, приоритет, описание, целевой узел;
    кнопка «перейти к блоку» подсвечивает цель на холсте).
  - Кнопки: **Применить изменения**, **Удалить**.
- Правая панель **«Настройки сценария»**: «Встроенные переменные» (свёрнуто) и
  **«Начальные переменные»** (доступны как `{varName}` в сообщениях и
  `context.variables.varName` в условиях) + «Добавить переменную».
- **JSON редактор** (Monaco): Перезагрузить · Форматировать · Сохранить, онлайн-валидация
  («✓ JSON валиден»). Можно вставить целиком сгенерированный сценарий и сохранить.

## Промпты (`/prompts`)

10 готовых шаблонов промптов по нишам (интернет-магазин, FAQ/поддержка, лидген, запись на
приём, ресторан/доставка, опрос/NPS, HR-скрининг, онбординг, универсальный ассистент).
У каждого: кнопка **Копировать**, тумблер **«Показать контекст платформы и JSON-схему»**,
кнопка **«Скопировать полный промпт»** (= спецификация платформы + бизнес-контекст + требования).
Подробнее — в [06 — Генерация сценариев через LLM](06-Генерация-сценариев-LLM.md).
