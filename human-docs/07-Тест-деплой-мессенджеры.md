# 07 — Тест, деплой, мессенджеры

## Принцип: сценарий ≠ канал

- **Сценарий** описывает логику диалога и **не привязан** к платформе.
- **Коннектор/мессенджер** подключает сценарий к конкретному каналу (Telegram, VK, WhatsApp,
  Max, Web). Один сценарий может работать сразу в нескольких каналах.
- Архитектура: ядро (сценарная машина) + отдельные модули под каждую соцсеть.

> Статус каналов (на момент записи): **Telegram работает стабильно**, **VK багается**
> («ВК не трогаем»). Остальные — по обстоятельствам. Сам редактор местами может багать —
> найденные баги фиксируем и кидаем разработчику.

## Тестирование сценария

1. **Предпросмотр / встроенный тест** — прямо в продукте есть «эмулятор мессенджера»,
   где можно прогнать сценарий вручную. Учти: часть подстановок переменных в эмуляторе может
   не отрабатывать — финально проверяй на реальном канале.
2. **Тест виджета** (`/widget-test`) — стенд для Web-виджета (см. ниже).
3. **Диалоги/Логи** — для разбора уже состоявшихся сессий (см. [08](08-Эксплуатация-аналитика-диалоги.md)).

## Подключение Telegram

1. Создай бота в Telegram через **@BotFather**, получи **токен**.
2. На странице «Боты» у нужного бота → **Мессенджеры** → добавить мессенджер **Telegram**
   (режим **pooling**) → вставить **токен** → включить.
3. Готово — бот отвечает по сценарию сразу.

## Сборка / запуск

- **Собрать** (в действиях бота) — собирает/применяет бота.
- **Статус** (тумблер в списке) — включает/выключает бота.
- **Цикличность** (тумблер) — после `end` диалог начинается заново с `start`
  (если бот «замолчал» в конце — включи).

## Web-виджет (`/widget-test`)

Тестовый стенд для встраиваемого чат-виджета (для ботов с мессенджером типа `web`).
Требования (из подсказки на странице):
- Виджет собран в `chat-widget/dist` (`npm run build` в папке `chat-widget`).
- Бэкенд запущен и доступен.
- У выбранного бота есть активный `web`-мессенджер.
- Файлы `chat-widget.js` и `chat-widget.css` доступны по `/chat-widget/dist/` (или прокси в Vite).

Управление на стенде: выбрать бота → **Инициализировать виджет** → **Показать / Скрыть /
Уничтожить / Перезагрузить виджет**. Виджет появляется в правом нижнем углу.
