# reference/07 — API, запуск бота и эксплуатация

Материал описывает типовой интеграционный контракт совместимой платформы. Пути и поля следует
сверить с документацией конкретного развёртывания перед использованием в рабочей среде.

## Авторизация и база API

- База: **`/api`** на хосте вашего развёртывания, например `https://bot-builder.example/api/...`.
- Авторизация: заголовок **`Authorization: Bearer <accessToken>`**, где
  `accessToken` лежит в `localStorage`. Рефреш — `POST /api/auth/refresh {refreshToken}` при 401.

## REST-эндпоинты (карта)

### Боты
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/bots` | список ботов |
| POST | `/api/bots` | создать бота |
| PUT | `/api/bots/{id}` | обновить (в т.ч. `{is_active}` — статус, `{is_cyclic}` — цикличность) |
| DELETE | `/api/bots/{id}` | удалить |
| POST | `/api/bots/import` | импорт сценария (JSON) |
| GET | `/api/bots/{id}/export` | экспорт JSON |
| GET | `/api/bots/{id}/build` | «Собрать» — скачать билд-артефакт (blob), НЕ деплой |
| POST | `/api/bots/{id}/test` | одношаговый тест `{userInput}` (сессию НЕ держит — см. ниже) |
| GET | `/api/bots/{id}/versions` | версии сценария |
| GET | `/api/bots/{id}/scheduled-messages` | очередь отложенных сообщений |

### Мессенджеры
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/messengers/bots/{id}/messengers` | каналы бота |
| POST | `/api/messengers/bots/{id}/messengers` | подключить канал |
| PUT | `/api/messengers/messengers/{id}` | изменить канал |
| DELETE | `/api/messengers/messengers/{id}` | удалить канал |
| POST | `/api/messengers/messengers/{id}/test` | тест-отправка `{testRecipient}` |

## Подключение Telegram (payload)

`POST /api/messengers/bots/{botId}/messengers`:
```json
{
  "messenger_type": "telegram",
  "connection_mode": "polling",
  "is_active": true,
  "credentials": { "telegram": { "botToken": "123456789:AA..." } }
}
```
- `connection_mode`: `polling` (Long Polling) или `webhook` (тогда нужны `webhook_url`, `webhook_secret`).
- Другие каналы: `whatsapp` → `credentials.whatsapp.{accessToken, phoneNumberId}`;
  `max` → `credentials.max.accessToken`; `web` → без токена.
- Токен берётся у @BotFather (`getMe` для проверки).

## Как бот «оживает»

Бот начинает отвечать в Telegram, когда **И** канал `is_active: true`, **И** бот включён
(`is_active` — тумблер «Статус» в списке). Polling запускается автоматически — отдельного
«деплоя» нет. Кнопка **«Собрать»** только скачивает билд-артефакт, на работу бота не влияет.
**Цикличность** (`is_cyclic`) — отдельный тумблер: после `end` диалог стартует заново с `start`.

## Предпросмотр / тест-движок

- **UI «Предпросмотр»** (`/preview/{botId}`) гоняет сценарий через **WebSocket (socket.io)** —
  это тот же движок, что и боевой. События:
  - `bot:start` `{ botId, sessionId }`
  - `bot:input` `{ sessionId, botId, input }`
  - `bot:stop` `{ sessionId }`
  - ответы приходят сообщениями через сокет; в UI показывается «Состояние: <id текущей ноды>».
- **REST `/api/bots/{id}/test {userInput}`** — упрощённый одношаговый тест: он **не держит сессию**
  (возвращает `{success, messages, states, sessionId}`, но многошаговый диалог через него не идёт).
  Для реального прогона диалога — UI «Предпросмотр» (socket) или сам мессенджер.

## Импорт JSON: способы

1. **UI «Боты → Импорт»** — загрузка `.json` файла (открывается файловый диалог).
2. **UI «Редактор → JSON редактор»** — вставить JSON в Monaco → «Форматировать» (валидация
   «✓ JSON валиден») → «Сохранить».
3. **API** — `POST /api/bots/import` с телом сценария.

## Подводные камни (проверено)

- ⚠️ **Прямая ссылка `/editor/{botId}` НЕ загружает бота** — редактор берёт бота из состояния
  приложения, которое выставляется кнопкой **«Редактировать»** в списке. По прямому URL
  откроется пустой новый сценарий («Создание нового бота», только start→end).
  Чтобы открыть существующего бота: **Боты → строка бота → «Редактировать»**.
- ⚠️ В **Предпросмотре** не подставляются переменные профиля: `{username}` пустой,
  `{messengerType}` = `web`. В реальном Telegram — заполняются. Это не баг сценария.
- ⚠️ **«Собрать» ≠ запуск.** Это скачивание билда. Запуск — через активные канал+бот (polling).
- ⚠️ В тест-эндпоинте `/api/bots/{id}/test` сессия не сохраняется — он застревает на `start`.
  Не пытайся гонять им многошаговый диалог; используй Предпросмотр.
- ⚠️ Диалоги/Логи: колонка **«Состояние»** = id текущей ноды, где «припаркован» пользователь
  (удобно для дебага: видно, на каком узле застрял).
